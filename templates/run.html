What the engine does

  1. Hygiene checks on all five tables (blank columns, blank keys, non-numeric amounts, unreadable dates, dates outside the month, duplicates, return amount / SKU / window checks). Every check is listed in the Excel output with Pass / Fail.
  2. Net sales per Packet ID: forward Sales amount minus RT Return amount; RTO only when the packet is not in RT.
  3. Net settlement per Order release ID: forward Settlement amount minus Reverse settlement amount.
  4. Compare on Packet ID = Order release ID; classify Matched / Unmatched / one-sided.
  5. Build the exception register (short/excess settlement, missing sides, id mismatches, commission & tax variances).

The names in italics are the fields you map to file columns in step 2; the SQL uses the columns you pick.
